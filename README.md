# CS-330
Comp Graphics &amp; Visualization

Software design primarily focuses on the features that solve the problems the software is being created for. I usually focus on creating something that works before making it user friendly and visually pleasing. I did the same thing with my visualizations by focusing on the major aspects of representing objects in a 3D space. I didn't stress over the appearance until the basic representation made the objects look similar enough to what they were meant to represent. Once the basic components of each item were in place, I understood how to modify and arrange them to make the appearance more interesting. If I focused too much on the final product, it's harder to start and work my way through the design.

I used an iterative design approach to add elements and modifications to the software as I learned new ways to modify the scene. This included the view modification, object modifications like textures, and the lighting. I was thinking of ways to modularize the code so it would be easier to implement new changes without repeating several function calls. 

Learning to create objects using OpenGL will help me create a finished product to display my creativity using what I've learned in multiple languages so far. Visual representation is a major selling point for most software, especially games and applications that users rely on daily. Visual appeal is a huge factor, so I intend to utilize OpenGL to transform one of my earlier projects into a presentable application.
